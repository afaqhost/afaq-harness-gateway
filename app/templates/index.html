05 / المستخدمون

المستخدمون والصلاحيات

OpenAI-Compatible API

توثيق API

AFAQ Gateway واجهة متوافقة مع OpenAI تتيح الوصول إلى نماذج الذكاء الاصطناعي من أي تطبيق. جميع النماذج المثبتة متاحة فورًا.

رابط القاعدة https://your-gateway.com/v1
المصادقة Bearer token مع كل طلب الموديلات GET /v1/models إرسال رسالة POST /v1/chat/completions البث المباشر SSE streaming الذاكرة سياق محفوظ تلقائيًا أخطاء شائعة 401 · 400 · 502 · 504

نظرة عامة

تدعم البوابة معايير OpenAI كاملة —authentication, list models, chat completions, streaming — مع إضافات خاصة بالبوابة.

✓OpenAI-compatible endpoints
✓Context memory per conversation
✓Streaming via SSE
✓Multi-harness support
✓API key management
✓Bilingual (Arabic / English)

المصادقة

Bearer Token

أنشئ مفتاح API من لوحة التحكم وأرسله في ترويسة Authorization مع كل طلب.

Header
Authorization: Bearer afaq_YOUR_KEY
مفتاح API

أنشئ مفتاح جديد من صفحة مفاتيح API. احفظه — لن يظهر كاملًا مرة أخرى.

جلب الموديلات

GET /v1/models

يعيد هذا المسار قائمة بجميع الموديلات المتاحة. كل موديل له معرف فريد بصيغة harness/provider/model.

curl
curl https://your-gateway.com/v1/models \
  -H "Authorization: Bearer afaq_YOUR_KEY"
import requests
resp = requests.get(
    "https://your-gateway.com/v1/models",
    headers={"Authorization": "Bearer afaq_YOUR_KEY"}
)
models = resp.json()["data"]
for m in models:
    print(m["id"])
const resp = await fetch("https://your-gateway.com/v1/models", {
  headers: { "Authorization": "Bearer " + process.env.AFAQ_API_KEY }
});
const { data } = await resp.json();
data.forEach(m => console.log(m.id));

صيغة معرف الموديل

كل معرف موديل يتكون من ثلاثة أجزاء مفصولة بـ //: اسم الهارنسس // المزود // اسم الموديل.

الصيغةharness//provider/model-name
مثالopencode//opencode/big-pickle
مثال آخرcommandcode//deepseek/deepseek-v4-flash

اختيار الموديل

استخدم صفحة الهارنسس لمشاهدة جميع الموديلات المتاحة، ثم اختر الموديل المناسب من القائمة.

الذاكرة السياقية

البوابة تحفظ سياق المحادثة تلقائيًا لكل محادثة على حدة. أرسل الطلبات إلى نفس المحادثة للحفاظ على السياق دون إعادة إرسال السجل الكامل.

كيف تعمل الذاكرة:
  • كل محادثة لها معرف فريد يتم إرفاقه بالطلبات
  • النظام يرسل السجل السابق تلقائيًا مع كل طلب
  • لا حاجة لإرسال entire conversation history في كل طلب
  • لبدء محادثة جديدة، أرسل الطلب بدون معرف محادثة سابقة

التعليمات النظامية

أضف role: system في مصفوفة الرسائل لتعيين سلوك الموديل. سيتم إرسالها مع كل طلب.

JSON Body
{
  "model": "opencode//opencode/big-pickle",
  "messages": [
    {"role": "system", "content": "You are a helpful assistant that speaks Arabic."},
    {"role": "user", "content": "ما هي عاصمة فرنسا؟"}
  ]
}

البث المباشر (Streaming)

stream: true

فعّل stream: true للحصول على الرد تدريجيًا عبر SSE. كل جزء يحتوي delta.content يتم إلحاقه بالرد. الطلب الناجح ينتهي بـ data: [DONE].

curl
curl https://your-gateway.com/v1/chat/completions \
  -H "Authorization: Bearer afaq_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "opencode//opencode/big-pickle",
    "messages": [{"role": "user", "content": "Hello"}],
    "stream": true
  }'
import os, requests
with requests.post(
    "https://your-gateway.com/v1/chat/completions",
    headers={"Authorization": f"Bearer {os.environ['AFAQ_API_KEY']}"},
    json={
        "model": "opencode//opencode/big-pickle",
        "messages": [{"role": "user", "content": "Hello"}],
        "stream": True
    },
    stream=True
) as resp:
    for line in resp.iter_lines():
        if line:
            data = line.decode().replace("data: ", "")
            if data == "[DONE]": break
            print(data, end="", flush=True)
const resp = await fetch("https://your-gateway.com/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.AFAQ_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "opencode//opencode/big-pickle",
    messages: [{ role: "user", content: "Hello" }],
    stream: true
  })
});
const reader = resp.body.getReader();
const decoder = new TextDecoder();
while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  const lines = decoder.decode(value).split("\n");
  for (const line of lines) {
    if (line.startsWith("data: ")) {
      const data = line.slice(6);
      if (data === "[DONE]") break;
      const delta = JSON.parse(data)?.choices?.[0]?.delta?.content;
      if (delta) process.stdout.write(delta);
    }
  }
}

أخطاء شائعة

401
Unauthorized

مفتاح API غير صالح أو انتهت صلاحيته. أنشئ مفتاحًا جديدًا من لوحة التحكم.

400
Bad Request

اسم هارنس غير معروف أو معرف موديل غير صحيح. تأكد من صيغة الموديل: harness//provider/model

502
Bad Gateway

خطأ في أداة CLI للهارنس. تأكد من تثبيت الهارنس وتشغيله بشكل صحيح.

504
Gateway Timeout

انتهت مهلة الاتصال بالموديل. جرب موديلًا آخر أو تحقق من اتصال الشبكة.
