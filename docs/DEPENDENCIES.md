# Dependencies

Keep dependencies minimal.

Preferred categories:

- HTTP framework/runtime;
- SQLite driver/ORM or thin query layer;
- schema validation;
- secure password/API-key hashing;
- frontend framework if needed;
- test framework;
- logging.

Do not add a dependency when a small standard-library implementation is safer and easier to maintain.

Before adding a dependency, record the reason, license, security posture, maintenance activity, and bundle/runtime impact.
